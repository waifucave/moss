> **Not released yet.** This page describes MOSS Code as it is being built for the first release.

A session's tab in MOSS Code has a row of panels beside its conversation. Each panel works in the session's own folder, on the computer that holds it.

| Panel | What it shows |
| :- | :- |
| **Terminal** | A terminal in the session's folder, on its computer. |
| **Changes** | What the session changed: each file against the version it started from, side by side or in one column. |
| **Files** | The session's folder as a tree you can filter, and the file that's open. |
| **Browser** | The MOSS Browser: tabs, back, forward and reload, an address bar, and the page itself, the same browser your bots use. |

Every panel is a plugin that MOSS ships, and a plugin can add a panel of its own. [Plugins](/docs/plugins/) says how plugins are added.
